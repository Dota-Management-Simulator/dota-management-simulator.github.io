# Match announcer and death timers

October 25, 2026 — local, not published.

Live matches and in-memory replays now put a ten-hero life strip, announcement banner and recent event feed immediately above the map. Dead portraits are dimmed and carry a match-clock respawn countdown; the same countdown appears beside heroes in both side panels and the live/replay rosters. The engine exposes its existing remaining respawn time rather than applying a new Dota respawn formula. Aegis revivals use the existing five-match-second resurrection. Between replay samples, event timestamps expose a death or revival only once it has happened. Old frames without this telemetry show unknown respawn timing rather than invented seconds.

The banner covers First Blood, Killing Spree (3 consecutive kills), Dominating (4), Mega Kill (5), Unstoppable (6), Wicked Sick (7), Monster Kill (8), Godlike (9), and Beyond Godlike (10+). Multi-kills use a separate chain: Double Kill, Triple Kill, Ultra Kill and Rampage, with at most 18 match seconds between successive credited kills. Death resets both counters; neutral deaths reset a streak without granting a kill or consuming First Blood. Aegis resurrection does not add a death or reset the streak. Shutdowns, actual tower destructions, Roshan kills and Ancient destruction also appear. These are presentation rules over the simulator's actual attribution, not new bounties or a complete historical ruleset. The naming/window reference is the [announcer archive](https://liquipedia.net/dota2/Announcer_responses) and [hero mechanics archive](https://dota2.fandom.com/wiki/Heroes/Mechanics).

**Enable announcer** turns on original default Dota 2 recordings and plays a short Mega Kill preview. The recordings are bundled locally (19 MP3s, 260,777 bytes) from the archived [Announcer.sb soundboard](https://github.com/matteo-pacini/DotA2-Soundboard/blob/master/DotA2Soundboard/Announcer.sb). The asset ledger records the original phrases, container hash and each extracted recording's size/SHA-256: [dota-announcer-assets.json](dota-announcer-assets.json). Game audio belongs to Valve; the archive's application code was not copied. The original highest-streak voice line contains its original profanity. Shutdown/Aegis notices are visual only. Tower, Roshan and victory audio use the actual Radiant/Dire side.

Sound starts only after the explicit control, can be switched off, and stops on pause, rewind, hidden tab, map change or unmount. High speeds keep at most the latest two queued clips instead of building a backlog. Enabling sound does not announce past events. An unavailable/blocked recording leaves the text visible and offers retry. New maps start with sound off.

The event ledger retains 90 match seconds in each transient frame; the feed shows the last four entries. Replay frames merge adjacent event windows by monotonic IDs and exclude future timestamps. No ledger or respawn telemetry enters compact saved player scoreboards, and no combat decisions, RNG draws, rewards, clock speed or save schema change. Existing engine respawn durations can be much longer than real Dota because engine seconds represent six match seconds.

Validation: focused tests cover kill attribution, first blood, streak and multi-kill resets/window boundaries, neutral deaths, Aegis timing, between-frame replay deaths, future-event filtering, deduplication, snapshot isolation and unchanged observed/unobserved simulation state. All 19 recordings decode successfully in the browser. Disposable localhost 5338 real-worker checks verify actual kills, minute stepping (65/105/104 seconds down to 5/45/44), sound control and all ten portraits with 390px/320px containment. The normal campaign save and background jobs are untouched.
