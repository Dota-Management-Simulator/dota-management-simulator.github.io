## Player progression balance — October 22, 2026 (published)

New player attributes start at 15–40 and develop through weekly practice; existing saved ratings remain intact. Combat power now uses `(0.4 + average(laning, teamfights, skirmish, stability) × 0.008 + difficulty bonus)` before energy, happiness, form and existing safety bounds. The former steep curve put nearly all new starting skills at the same minimum power. This gentler curve preserves differences and development across the starting range. Skill lookups use nullish defaults so a real zero from decay never becomes a fallback 70. Future matches use the revised model; stored outcomes and scoreboards are retained. A new engine test covers low-skill power ordering and zero ratings. The October 23 staff revamp removes the analyst's flat power bonus: staff now improve targeted patch knowledge and hero discovery, and each team auto-drafts from its perceived report while combat uses patch truth. See [staff research](staff-research.md) and [training and world development](training.md).

The match engine is a TypeScript adaptation of the user's **Lane Siege** HTML prototype, preserved in `reference/lane-siege-original.html`. The original repository entry point and README are preserved separately as `reference/original-index.html` and `reference/original-README.md`; the original commit history is retained in the publishing checkout. Reused concepts: three lanes, two towers per lane, creep waves, attribute scaling, basic attacks, four ability archetypes, healing and retreat, nearby experience, respawn, and Ancient destruction.

The TI1 opening pool contains 46 heroes documented as contested at The International 2011 by [Spectral Stats](https://stats.ru.spectral.gg/lrg2/?league=ti1&mod=heroes), cross-checked against [Liquipedia's TI1 hero statistics](https://liquipedia.net/dota2/The_International/Hero_Statistics/2011). This includes Axe, who was banned but not picked. Modern names are used for renamed heroes. Hero membership is sourced; all combat values, role preferences, attributes and ability archetypes are deliberately simplified placeholders.

Annual Dota 2 release batches in `src/data/hero-releases.json` add 81 heroes through 2026, producing a 127-hero catalog. The current year's additions unlock together at week 17, the post-TI shuffle, even if a real release occurred later in that calendar year. Earlier starts cannot draft future heroes. Later starts include completed prior shuffles; years after 2026 keep the latest pool. The worker receives the eligible cutoff explicitly. Global hero lookups still resolve old saved scoreboards independently of the current pool.

Release years follow the [release chronology](https://liquipedia.net/dota2/Heroes_by_release), with Oracle corrected to 2014 using [Valve's Foreseer's Contract update](https://www.dota2.com/oracle/day2). Current catalog metadata comes from [OpenDota constants](https://github.com/odota/dotaconstants/blob/master/build/heroes.json). No additional 2026 hero is recorded by the October 21 research cutoff. Unlocking by calendar-year shuffle is a user-selected game rule, not historical Captain's Mode eligibility or exact patch balance. The 2020 campaign still has the placeholder TI event; the roster batch explicitly uses online regional events because no historical TI occurred that year.

Results are best-of-three event deciders, not full tournament brackets. Actual Ancient destructions decide each game; two game wins decide the series. Gold and XP series are sampled from the engine's running totals. Gold represents accumulated resources with abstract automatic item scaling, not a complete shop/inventory economy. Assists count distinct recent enemy-hero damage contributors, excluding the credited killer. Creeps can secure uncredited hero kills. Nearby allies share XP; levels cap at 25. A hero's cumulative XP continues to be recorded at the cap.

The simulation runs in a Web Worker. Watching, speeding up, pausing, and skipping affect only playback, never the outcome or rewards. Frames stay in memory; small scoreboards and resource timelines persist with campaign history. Old saves/results remain readable; old roll-based results do not invent detailed match data.

Playback now uses Valve's actual Dota 2 minimap icons for all 127 catalog heroes, with matching icons in live rosters and result scoreboards. Team-colored rings, health bars, death fading and hover names remain. Each transient replay hero carries its exact catalog `heroId`, so icons follow that game's draft without matching display names. Unknown or failed images fall back to initials. This is a visual change; the engine rules and save format are unchanged. Artwork is current reference art, not a recreation of historical icon versions.

The 127 original PNGs ship in `public/hero-icons/` (about 667 kB total), so playback makes no image requests to external services. `src/data/hero-icons.json` records each source URL and Valve's internal name. Regenerate with `node scripts/import-hero-icons.mjs`; it joins exact English identities from [Valve's hero feed](https://www.dota2.com/datafeed/herolist?language=english) to the existing catalog and downloads [Valve's minimap artwork](https://cdn.steamstatic.com/apps/dota2/images/dota_react/heroes/icons/antimage.png). Dota 2 artwork belongs to Valve Corporation; no separate open license is claimed.

One engine second represents six match-clock seconds. Combat constants are calibrated for a bounded prototype. Late-game creep siege ramps up to break stalemates. After the overtime threshold, both Ancients take periodic siege attrition weighted by the opposing side's surviving heroes and destroyed towers. Overtime is identified in the result. In the rare case that both Ancients fall on the same tick, accumulated team gold breaks the tie. There is no win-probability coin flip or predetermined winner.

## Player performance telemetry — October 22, 2026

**October 23 local patch integration:** new match configurations now carry one of two composite patches per TI season. Seven axes change actual combat/economy/awareness/objective behavior; featured hero bonuses and strategic tags affect auto-drafting. Managed and AI tournament workers use the same pinned patch. New saved managed/compact AI scoreboards retain patch metadata without rewriting old results. Numerical balance and hero priorities are estimates, with source coverage/gaps exposed. See [patch mechanics, timing and source ledger](patches.md).

New scoreboards also record effective hero/building damage, ability healing and assigned-lane outcome at 10:00. These are observational counters with no extra RNG draws or outcome modifiers. Player profiles aggregate saved weekly series, managed tournament series and compact AI tournament scoreboards into event/hero/career statistics. Existing missing telemetry remains unknown; wards and dewards have no engine model. See [performance definitions, ratings and save rules](performance.md). This feature is local, not deployed.
